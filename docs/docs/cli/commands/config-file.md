# hivepaas config-file

Config files: an nginx.conf, a settings.yaml, kept by HivePaaS for an app, or - with --scope env or --scope project - for its environment or its project, whose apps get them unless --no-inheritable. A setting mount, made in the dashboard, puts one at a path in an app's containers; a change reaches them on its own, without a deployment.

```text
hivepaas config-file [command]
```

Aliases: `config-file`, `config-files`

Flags:

| Flag | Description |
| --- | --- |
| `--scope string` | whose config files: the app's, its environment's (env) or its project's (project) (default: `app`) |

## hivepaas config-file push

Add a config file, or change the one of that name, with FILE's content; - reads stdin. A file that is not text is kept as it is. It is shared below unless --no-inheritable: an app's with its pull request previews, an environment's or a project's with their apps. One changed keeps how it is shared unless told.

```text
hivepaas config-file push NAME FILE [flags]
```

Examples:

```bash
hivepaas config-file push nginx-conf ./nginx.conf
hivepaas config-file push ca-bundle ./ca.pem --scope project
```

Flags:

| Flag | Description |
| --- | --- |
| `--inheritable` | shared below: with an app's pull request previews, an environment's or a project's apps (default) |
| `--no-inheritable` | not shared below |
| `--no-previews` | an app's: its pull request previews do not get it |
| `--previews` | an app's: its pull request previews get it too (default) |
| `--scope string` | whose config files: the app's, its environment's (env) or its project's (project) (default: `app`) |
