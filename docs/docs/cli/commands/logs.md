# hivepaas logs

Show an app's logs, or with --deployment a deployment's, with --task a task's.

With -f the command follows them until Ctrl-C, and opens the stream again when it drops. With -o json each line is a JSON object of its own: \{type, data, ts\}.

--search, --level and --history read the stored logs instead, those of containers that no longer exist too: the last hour unless --since says otherwise, the newest lines first cut.

```text
hivepaas logs [flags]
```

Examples:

```bash
hivepaas logs -f --since 10m
hivepaas logs --search timeout --level error,warn --since 1d
hivepaas logs --deployment 01JA2C7W... -f
hivepaas logs --task 01JA2D8X... -f
```

Flags:

| Flag | Description |
| --- | --- |
| `--deployment string` | a deployment's logs, by its id |
| `-f, --follow` | follow the logs as they are written |
| `--history` | the stored logs, without a search |
| `--level strings` | stored lines of these levels: trace, debug, info, warn, error, fatal, panic |
| `--match-case` | --search tells upper from lower case |
| `--no-timestamps` | leave out each line's time |
| `--regex` | --search is a regular expression |
| `--search string` | stored lines with this text, from the start of a word |
| `--since string` | from a time ago, such as 10m or 2h, or from an RFC 3339 time |
| `--tail int` | the last so many lines: the server's default for an app is 1000 |
| `--task string` | a task's logs, by its id: a job's run, for one |
| `--until string` | stored lines before this RFC 3339 time |

The [global flags](./index.md#global-flags) apply to every command.
