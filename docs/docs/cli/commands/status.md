# hivepaas status

What Home's "Needs attention" lists, for the whole installation: an app that is not running or keeps restarting, a node that is down or over-committed - with where, since when and what is known. --fail exits 1 when anything is listed, for a script that checks.

```text
hivepaas status [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--fail` | exit 1 when anything needs attention |

The [global flags](./index.md#global-flags) apply to every command.
