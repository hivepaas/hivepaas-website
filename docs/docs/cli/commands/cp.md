# hivepaas cp

Copy between this machine and one of an app's containers. The container's side is :PATH, for the app -a names or the directory's link, or APP:PATH. A directory is copied as itself, into DST; SRC/. copies what is in it instead. A file to a PATH ending in / keeps its name; a file never replaces a directory of that name in the container.

The copy goes to a running container of the app: --replica picks which. A copy into it that stops part way - Ctrl-C, a cut connection - leaves there what reached it: a file partly written, some of a directory's files.

```text
hivepaas cp SRC DST [flags]
```

Examples:

```bash
hivepaas cp ./config.yaml :/app/config.yaml
hivepaas cp ./site/. :/usr/share/nginx/html
hivepaas cp api:/var/log/app.log .
hivepaas cp :/data/exports ./exports --replica 2
```

Flags:

| Flag | Description |
| --- | --- |
| `--replica int` | the replica to copy to or from, as ps numbers them |
| `--timeout duration` | how long the copy may take (default: `30m0s`) |

The [global flags](./index.md#global-flags) apply to every command.
