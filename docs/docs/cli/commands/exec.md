# hivepaas exec

Open a shell in an app's container: sh, or the one --shell names, in one of its running containers. At a terminal the keys go to the shell as they are typed, Ctrl-C included; exit, or Ctrl-D, ends it. Piped in, the input is typed into the shell, which ends with it.

The key needs the execute action, and the app's terminal must be on (its settings).

```text
hivepaas exec [APP] [flags]
```

Aliases: `exec`, `ssh`

Examples:

```bash
hivepaas exec
hivepaas exec worker --shell bash
echo 'df -h' | hivepaas exec db
```

Flags:

| Flag | Description |
| --- | --- |
| `--shell string` | sh, bash, zsh or fish: sh when left out |

The [global flags](./index.md#global-flags) apply to every command.
