# hivepaas open

Open an app's address in the browser: the first of its addresses, its domain or a published port. --print writes them instead, one a line, for a script or a machine with no browser.

```text
hivepaas open [APP] [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--print` | write the addresses instead of opening one |

The [global flags](./index.md#global-flags) apply to every command.
