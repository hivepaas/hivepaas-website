# hivepaas project

Projects and their environments

```text
hivepaas project [command]
```

Aliases: `project`, `projects`

## hivepaas project create

Create a project. Its environments are those --envs names, development and production unless given: lowercase letters, digits, - and _, starting with a letter.

```text
hivepaas project create NAME [flags]
```

Examples:

```bash
hivepaas project create shop
hivepaas project create shop --envs staging,production
```

Flags:

| Flag | Description |
| --- | --- |
| `--envs strings` | the project's environments, with commas |
| `--note string` | a note on the project |

## hivepaas project delete

Delete a project: its environments and all their apps. Their data on the volumes stays unless --remove-storage.

At a terminal it asks for the project's name to be typed; elsewhere it needs --yes.

```text
hivepaas project delete [PROJECT] [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--remove-storage` | delete the data the apps keep on volumes too |
| `-y, --yes` | do not ask: for a script |

## hivepaas project env

A project's environments: add one, remove one

```text
hivepaas project env [command]
```

### hivepaas project env add

Add an environment to a project

```text
hivepaas project env add NAME [flags]
```

Examples:

```bash
hivepaas project env add staging -p shop
```

Flags:

| Flag | Description |
| --- | --- |
| `--color string` | its color in the dashboard, such as #0ea5e9 |

### hivepaas project env rm

Remove an environment and all its apps. Their data on the volumes stays unless --remove-storage.

At a terminal it asks for the environment's name to be typed; elsewhere it needs --yes.

```text
hivepaas project env rm NAME [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--remove-storage` | delete the data the apps keep on volumes too |
| `-y, --yes` | do not ask: for a script |
