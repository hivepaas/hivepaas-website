# hivepaas preview

An app's previews: the copies HivePaaS makes of it for a branch or a pull request, each an app of its own - -a takes it for logs, deploy and the rest.

```text
hivepaas preview [command]
```

Aliases: `preview`, `previews`

## hivepaas preview create

Make a preview of an app: a copy of it, built from --ref - the app's own branch by default - deployed at a subdomain of its own. The secrets a preview is not given are said. The command waits for the task that makes it, following its log; Ctrl-C stops the waiting, not the task.

```text
hivepaas preview create [flags]
```

Examples:

```bash
hivepaas preview create --ref feature/checkout
hivepaas preview create --ref feature/checkout --subdomain checkout --no-db
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-db` | do not clone the databases the app uses |
| `--no-start` | make it, and do not start it |
| `--no-wait` | start making it and return |
| `--ref string` | the branch to build; the one the app deploys from when not given |
| `--subdomain string` | the preview's subdomain; one is made when not given |
| `--timeout duration` | how long to wait (default: `30m0s`) |

## hivepaas preview ls

List an app's previews

```text
hivepaas preview ls [APP]
```

## hivepaas preview rm

Delete one of the app's previews, by its name or key, as app delete deletes an app: asked at a terminal, --yes elsewhere. A name that is not one of the app's previews is refused.

```text
hivepaas preview rm PREVIEW [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--remove-storage` | delete the data it keeps on volumes too |
| `-y, --yes` | do not ask: for a script |

The [global flags](./index.md#global-flags) apply to every command.
