# hivepaas completion

Generate the autocompletion script for hivepaas for the specified shell. See each sub-command's help for details on how to use the generated script.

```text
hivepaas completion [command]
```

## hivepaas completion bash

Generate the autocompletion script for the bash shell.

This script depends on the 'bash-completion' package. If it is not installed already, you can install it via your OS's package manager.

To load completions in your current shell session:

source &lt;(hivepaas completion bash)

To load completions for every new session, execute once:

#### Linux:

hivepaas completion bash > /etc/bash_completion.d/hivepaas

#### macOS:

hivepaas completion bash > $(brew --prefix)/etc/bash_completion.d/hivepaas

You will need to start a new shell for this setup to take effect.

```text
hivepaas completion bash
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-descriptions` | disable completion descriptions |

## hivepaas completion fish

Generate the autocompletion script for the fish shell.

To load completions in your current shell session:

hivepaas completion fish | source

To load completions for every new session, execute once:

hivepaas completion fish > ~/.config/fish/completions/hivepaas.fish

You will need to start a new shell for this setup to take effect.

```text
hivepaas completion fish [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-descriptions` | disable completion descriptions |

## hivepaas completion powershell

Generate the autocompletion script for powershell.

To load completions in your current shell session:

hivepaas completion powershell | Out-String | Invoke-Expression

To load completions for every new session, add the output of the above command to your powershell profile.

```text
hivepaas completion powershell [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-descriptions` | disable completion descriptions |

## hivepaas completion zsh

Generate the autocompletion script for the zsh shell.

If shell completion is not already enabled in your environment you will need to enable it. You can execute the following once:

echo "autoload -U compinit; compinit" >> ~/.zshrc

To load completions in your current shell session:

source &lt;(hivepaas completion zsh)

To load completions for every new session, execute once:

#### Linux:

hivepaas completion zsh > "$\{fpath[1]\}/_hivepaas"

#### macOS:

hivepaas completion zsh > $(brew --prefix)/share/zsh/site-functions/_hivepaas

You will need to start a new shell for this setup to take effect.

```text
hivepaas completion zsh [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-descriptions` | disable completion descriptions |

The [global flags](./index.md#global-flags) apply to every command.
