# hivepaas ps

List the Swarm tasks of an app's service: each replica's current task and the ones before it, the node it is on, its container, and the error of one that failed.

```text
hivepaas ps [APP] [flags]
```

Examples:

```bash
hivepaas ps
hivepaas ps api --state running
```

Flags:

| Flag | Description |
| --- | --- |
| `--state string` | only the tasks in these states, such as running or failed - several with commas |

The [global flags](./index.md#global-flags) apply to every command.
