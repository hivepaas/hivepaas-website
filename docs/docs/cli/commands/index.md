## Global flags

Every command takes these:

| Flag | Description |
| --- | --- |
| `-a, --app string` | app, by name, key or id |
| `--context string` | the installation to use, instead of the current one |
| `--debug` | log each request to stderr |
| `-e, --env string` | environment, by name |
| `--no-color` | no colors |
| `-o, --output string` | table, json or yaml (default: `table`) |
| `-p, --project string` | project, by name, key or id |
