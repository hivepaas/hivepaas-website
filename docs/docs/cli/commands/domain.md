# hivepaas domain

An app's domains

```text
hivepaas domain [command]
```

Aliases: `domain`, `domains`

## hivepaas domain add

Serve an app on a domain, over HTTP, its requests to HTTP sent on to HTTPS unless --no-force-https. The port is the app's, the first domain's, or --port. An app not exposed publicly is exposed: a domain is served only then. Headers, limits, paths and certificates are the dashboard's.

```text
hivepaas domain add DOMAIN [flags]
```

Examples:

```bash
hivepaas domain add api.shop.example.com
hivepaas domain add admin.shop.example.com --port 9000
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-force-https` | serve plain HTTP too, without sending it on to HTTPS |
| `--port int` | the app's port the domain is served from |

## hivepaas domain ls

List an app's domains

```text
hivepaas domain ls
```

## hivepaas domain rm

Stop serving an app on a domain

```text
hivepaas domain rm DOMAIN
```

The [global flags](./index.md#global-flags) apply to every command.
