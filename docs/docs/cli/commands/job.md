# hivepaas job

An app's scheduled jobs: list them, run one now, turn one on or off

```text
hivepaas job [command]
```

Aliases: `job`, `jobs`

## hivepaas job disable

Turn a scheduled job off: it does not run on its schedule

```text
hivepaas job disable JOB
```

## hivepaas job enable

Turn a scheduled job on: it runs on its schedule again

```text
hivepaas job enable JOB
```

## hivepaas job ls

List an app's scheduled jobs

```text
hivepaas job ls
```

## hivepaas job run

Run one of the app's scheduled jobs now, by its name or id, besides its schedule. The command waits for the run, following its logs on stderr; Ctrl-C stops the waiting, not the run: `hivepaas task cancel` cancels it. A run that fails exits 8.

```text
hivepaas job run JOB [flags]
```

Examples:

```bash
hivepaas job run migrate
hivepaas job run nightly-report --no-wait
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-wait` | start the run and return |
| `--timeout duration` | how long to wait for the run (default: `30m0s`) |

The [global flags](./index.md#global-flags) apply to every command.
