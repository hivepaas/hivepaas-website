# hivepaas deploy

Deploy an app: the image it runs, or a build of its repository. The flags of its source - --image, or --repo, --ref, --commit and the rest - and of its commands change the deployment settings first, in one write, which deploys them. `hivepaas deploy settings` shows them.

The command waits for the deployment to finish, following its logs on stderr. Ctrl-C stops the waiting, not the deployment: `hivepaas deploy cancel` cancels it.

```text
hivepaas deploy [flags]
hivepaas deploy [command]
```

Examples:

```bash
hivepaas deploy --image ghcr.io/acme/api:1.4.3
hivepaas deploy --commit $GITHUB_SHA
hivepaas deploy --ref release --dockerfile docker/Dockerfile --push-to ghcr
hivepaas deploy --use repo --repo https://github.com/acme/api.git --git-credential acme
```

Flags:

| Flag | Description |
| --- | --- |
| `--auto-deploy` | deploy each push to the ref |
| `--change-id string` | what the deployment is for: pr-12 has its result commented on that pull request |
| `--command string` | the container's command; "" for the image's |
| `--commit string` | build this commit, its full SHA, and stay at it; none to follow the ref |
| `--dockerfile string` | the Dockerfile's path in the repository |
| `--dockerfile-auto` | generate the Dockerfile from the source |
| `--dockerfile-inline string` | use this local file as the Dockerfile, kept in the settings; - reads stdin |
| `--entrypoint string` | the container's entrypoint; "" for the image's |
| `--git-credential string` | clone with this git credential; none for none |
| `--image string` | deploy this image: ghcr.io/acme/api:1.4.3 |
| `--lfs` | fetch the Git LFS files |
| `--no-auto-deploy` | do not deploy on push |
| `--no-cache` | build without the build cache |
| `--no-lfs` | do not fetch the Git LFS files |
| `--no-submodules` | do not clone the git submodules |
| `--no-wait` | start the deployment and return |
| `--post-deploy string` | a command run after each deployment; "" for none |
| `--pre-deploy string` | a command run before each deployment; "" for none |
| `--push-to string` | push the built image to the registry of this credential; none keeps it on the node |
| `--ref string` | the branch to build, or tags/NAME for a tag |
| `--registry-auth string` | pull the image with this registry credential; none for none |
| `--repo string` | build this git repository: https://github.com/acme/api.git |
| `--scan-path string` | the directory a generated Dockerfile is made from |
| `--submodules` | clone the git submodules |
| `--timeout duration` | how long to wait for the deployment (default: `30m0s`) |
| `--use string` | switch what the app deploys: image, or repo |
| `--workdir string` | the container's working directory; "" for the image's |

## hivepaas deploy cancel

Cancel a deployment: the app's running one when no id is given

```text
hivepaas deploy cancel [DEPLOYMENT-ID]
```

## hivepaas deploy get

Show a deployment

```text
hivepaas deploy get DEPLOYMENT-ID
```

## hivepaas deploy ls

List an app's deployments, the newest first

```text
hivepaas deploy ls [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--limit int` | how many to show (default: `20`) |
| `--status string` | only these: not-started, in-progress, done, failed, canceled - several with commas |

## hivepaas deploy settings

Show what an app deploys: its image or its repository, and its commands

```text
hivepaas deploy settings
```

The [global flags](./index.md#global-flags) apply to every command.
