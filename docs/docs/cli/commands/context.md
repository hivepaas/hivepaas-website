# hivepaas context

The installations the CLI is logged in to

```text
hivepaas context [command]
```

Aliases: `context`, `contexts`

## hivepaas context ls

List the contexts

```text
hivepaas context ls
```

## hivepaas context rm

Forget a context and its key's secret

```text
hivepaas context rm NAME
```

## hivepaas context use

Make a context the current one

```text
hivepaas context use NAME
```

The [global flags](./index.md#global-flags) apply to every command.
