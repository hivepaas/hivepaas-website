# hivepaas db

A managed database, made from a managed template: its engine archives it, and it can be restored into a new app to any moment its archive reaches. The dashboard restores it.

```text
hivepaas db [command]
```

## hivepaas db mark

Name this moment of a managed database: a restore point, which a restore into a new app recovers to exactly. It is listed once the log it is in is archived. It can be restored to for as long as retention keeps the base backup before it - about retainFull nights - or until --keep-until, at most 90 days ahead, which holds retention back and costs the storage of everything archived from it on. A name is letters, digits, '.', '_' and '-', at most 63, unique in the app; hp- is HivePaaS's own.

```text
hivepaas db mark NAME [flags]
```

Examples:

```bash
hivepaas db mark before-v42 -a shop-db
hivepaas db mark q4-release --keep-until 2026-12-31 --note "before the Q4 release"
```

Flags:

| Flag | Description |
| --- | --- |
| `--keep-until string` | hold retention back for the point until then: a date (2026-12-31) or an RFC 3339 time |
| `--note string` | what the moment is, for whoever restores to it |

The [global flags](./index.md#global-flags) apply to every command.
