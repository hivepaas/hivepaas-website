# hivepaas task

An app's tasks: its jobs' runs, and what else runs in the background for it

```text
hivepaas task [command]
```

Aliases: `task`, `tasks`

## hivepaas task cancel

Cancel a task

```text
hivepaas task cancel TASK-ID
```

## hivepaas task get

Show a task

```text
hivepaas task get TASK-ID
```

## hivepaas task ls

List an app's tasks, the newest first

```text
hivepaas task ls [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--limit int` | how many to show (default: `20`) |
| `--status string` | only these: not-started, in-progress, done, failed, canceled - several with commas |
| `--type string` | only these types, such as sched-job-exec - several with commas |

The [global flags](./index.md#global-flags) apply to every command.
