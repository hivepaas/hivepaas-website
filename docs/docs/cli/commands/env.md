# hivepaas env

An app's environment variables

```text
hivepaas env [command]
```

## hivepaas env ls

List an app's environment variables

```text
hivepaas env ls [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--all` | with those HivePaaS sets and those the app inherits |
| `--build` | only the build-time variables |
| `--shared` | only the shared variables |

## hivepaas env pull

Write the variables an app runs with as a .env file: those it inherits, its shared ones and its runtime ones, or with --build its build-time ones - the app's own over what it inherits. Those HivePaaS sets, which describe the app where it runs, are left out. A value naming others, $\{db.HIVEPAAS_URL\}, is written as it is: only the server expands it.

Without FILE it writes to stdout. A FILE that exists is replaced only with --force; the file is made readable by you alone, for it holds secrets.

```text
hivepaas env pull [FILE] [flags]
```

Examples:

```bash
hivepaas env pull .env.local
hivepaas env pull -a worker > worker.env
```

Flags:

| Flag | Description |
| --- | --- |
| `--build` | the build-time variables instead of the runtime ones |
| `--force` | replace FILE when it exists |

## hivepaas env set

Set environment variables of an app: the runtime ones, or with --build or --shared the build-time or shared ones. A value may name others, $\{db.HIVEPAAS_URL\}, unless --literal.

--file sets those of a .env file, - for stdin; KEY=VALUE arguments beside it win.

```text
hivepaas env set [KEY=VALUE...] [flags]
```

Examples:

```bash
hivepaas env set LOG_LEVEL=debug FEATURE_X=on
hivepaas env set --file .env.production
hivepaas env set --build NODE_ENV=production
```

Flags:

| Flag | Description |
| --- | --- |
| `--build` | set the build-time variables |
| `--file string` | set the variables of this .env file; - reads stdin |
| `--literal` | take the values as they are, without expanding $\{...\} |
| `--shared` | set the shared variables |

## hivepaas env unset

Remove environment variables of an app

```text
hivepaas env unset KEY... [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--build` | remove from the build-time variables |
| `--shared` | remove from the shared variables |

The [global flags](./index.md#global-flags) apply to every command.
