# hivepaas backup

An app's data backups: snapshots of its volumes, made by its data backup jobs into backup repositories. A snapshot is given by its id or short id, as ls shows them.

```text
hivepaas backup [command]
```

Aliases: `backup`, `backups`

## hivepaas backup download

Write the file at PATH of a snapshot to -O FILE - by default PATH's last part, here - or with -O - to stdout. A file that is there is replaced with --force alone, once the whole file has come.

```text
hivepaas backup download SNAPSHOT PATH [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--force` | replace the file when it exists |
| `-O, --output-file string` | the file to write; - for stdout |

## hivepaas backup files

List what a snapshot holds, at a path

```text
hivepaas backup files SNAPSHOT [PATH]
```

## hivepaas backup ls

List an app's snapshots, the newest first

```text
hivepaas backup ls [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--repo string` | only the snapshots of this backup repository |

## hivepaas backup restore

Write a snapshot back into an app's volume - where its job backed it up, when the data goes back into the app it came from - and wait for the task, following its log. replace, the mode by default, makes the directory what it was, the old one kept aside, the app stopped during it; overwrite writes over what is there. It changes data: asked at a terminal, --yes elsewhere.

```text
hivepaas backup restore SNAPSHOT [flags]
```

Examples:

```bash
hivepaas backup restore a1b2c3d4
hivepaas backup restore a1b2c3d4 --to api-staging --volume data --subpath uploads --yes
```

Flags:

| Flag | Description |
| --- | --- |
| `--mode string` | replace or overwrite (default: `replace`) |
| `--no-wait` | start the restore and return |
| `--path string` | a directory of the snapshot to restore alone |
| `--stop-app` | stop the app during an overwrite, start it after; replace always does |
| `--subpath string` | where in the volume |
| `--timeout duration` | how long to wait for it (default: `2h0m0s`) |
| `--to string` | another app of the environment to write into |
| `--volume string` | the volume to write into, by name or id |
| `-y, --yes` | do not ask: for a script |

## hivepaas backup rm

Delete a snapshot from its repository

```text
hivepaas backup rm SNAPSHOT [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `-y, --yes` | do not ask: for a script |

## hivepaas backup run

Run one of the app's data backup jobs now, and wait for it as job run does: the app's one data backup job when it has one, else the one JOB names.

```text
hivepaas backup run [JOB] [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--no-wait` | start the run and return |
| `--timeout duration` | how long to wait for the run (default: `30m0s`) |

The [global flags](./index.md#global-flags) apply to every command.
