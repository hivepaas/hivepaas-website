# hivepaas template

The template store

```text
hivepaas template [command]
```

Aliases: `template`, `templates`

## hivepaas template deploy

Create an app from a template of the store, with the apps it depends on, and deploy them.

--param NAME=VALUE gives a parameter, and --dep-param DEP.NAME=VALUE one of a dependency's: a volume by its name, an app by its name or key. A volume parameter left out takes the project's only volume.

First the server checks what a previous install left where the new apps would keep their data. If it finds some, the apps are created only with --keep-storage, to start on it, or --reset-storage, to delete it first - or with the answer to a question in a terminal.

```text
hivepaas template deploy TEMPLATE [flags]
```

Examples:

```bash
hivepaas template deploy postgres --name orders-db -p shop -e staging --param dataVolume=default
```

Flags:

| Flag | Description |
| --- | --- |
| `--dep-param stringArray` | a dependency's parameter, DEP.NAME=VALUE |
| `--image-tag string` | an image tag instead of the version's |
| `--keep-storage` | create the apps on what a previous install left |
| `--name string` | the app's name: the template's when left out |
| `--no-wait` | create the apps and return, without waiting for their deployments |
| `--param stringArray` | a parameter, NAME=VALUE; repeat for more |
| `--reset-storage` | delete what a previous install left, then create |
| `--timeout duration` | how long to wait for the deployments (default: `30m0s`) |
| `--variant string` | the version's variant: its default when left out |
| `--version string` | the template's version: its default when left out |

## hivepaas template ls

List the templates

```text
hivepaas template ls [flags]
```

Flags:

| Flag | Description |
| --- | --- |
| `--category string` | a category, such as databases or databases/sql |
| `--search string` | match name, title, tagline, tags and aliases |
| `--sort string` | name, popular, trending or new (default: `name`) |

The [global flags](./index.md#global-flags) apply to every command.
