# Getting help

## Where to ask

- **[Discord](https://discord.com/invite/2TgD3zDb2e)** - questions, and help from the team and the community.
- **[GitHub Discussions](https://github.com/hivepaas/hivepaas/discussions)** - ideas, and questions worth keeping for the next person.
- **[GitHub Issues](https://github.com/hivepaas/hivepaas/issues)** - bugs, and features you would like.

## What to include

A question with these gets an answer sooner:

- **The HivePaaS version**, from the dashboard, under System > HivePaaS.
- **What you did, what you expected, and what happened instead.**
- **The error**, as the dashboard or the API showed it: its code, such as `ERR_NO_SESSION`, says the most.
- **Logs**: the app's or the deployment's, and for a problem with HivePaaS itself, its system errors.
- **Your setup**, when it matters: one server or several, and the OS.

Take secrets out first: passwords, API keys, tokens and private keys can appear in
logs and in env vars.
